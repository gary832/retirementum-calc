# retirementum-calc

Finished calculator file for the RetireMentum Perspective funnel. No payout tables, test cases or notes.

- Each release is a versioned, unchanging file (for example `rm-calc-1.0.0.min.js`). A published version is never edited; a fix ships as a new version.
- The funnel loads the file with a SHA-384 integrity lock, so a browser refuses to run any copy that differs from the tested version.
- `.nojekyll` tells GitHub Pages to serve files exactly as stored.
